# 박재현의 포트폴리오

> React와 TypeScript를 활용하여 제작한 포트폴리오 웹사이트입니다.



## Live Demo
**https://ppjjhh2001.github.io/my-portfolio/**

---

## 주요 기능 및 특징
- **다크 모드 UI**: 시각적 편안함을 주는 세련된 다크 테마 디자인
- **반응형 디자인**: PC와 모바일 어디서든 최적화된 화면 제공
- **글래스모피즘**: 상단 헤더에 투명한 유리 질감 효과 적용
- **프로젝트 상세 소개**: 주요 구현 기능 및 기술 스택 상세 기술
- **자동 배포**: GitHub Actions/Pages를 활용한 빠르고 간편한 배포 환경 구축

## 사용 기술 (Tech Stack)
- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Inline Styles (CSS-in-JS), CSS3
- **Deployment**: GitHub Pages

## 폴더 구조 (Project Structure)
```text
src/
 ┣ assets/      # 이미지 및 정적 자원
 ┣ components/  # 재사용 가능한 UI 컴포넌트 (Header, Card 등)
 ┣ sections/    # 페이지의 각 섹션 (Hero, Projects, Contact)
 ┣ data/        # 포트폴리오 텍스트 데이터 관리
 ┣ App.tsx      # 메인 조립 파일
 ┗ index.css    # 전역 스타일 설정
